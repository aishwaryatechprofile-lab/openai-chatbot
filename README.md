# AI Chatbot

## Description

This project is an AI-powered chatbot developed using Python, Streamlit, LangChain, and Groq. It allows users to enter questions and receive AI-generated responses through a simple and interactive web interface.

## Features

* Interactive chatbot interface
* AI-generated answers to user questions
* Simple and user-friendly design
* Integration with a Groq language model

## Technologies Used

* Python
* Streamlit
* LangChain
* Groq API

## Installation and Usage

1. Install the required packages:
   `pip install -r requirements.txt`
2. Add your Groq API key to a `.env` file.
3. Start the application:
   `streamlit run app.py`

## Security

Never upload your `.env` file or API key to GitHub.
